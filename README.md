# 20 соток — сайт студии инженерного благоустройства

React-версия сайта 20sotok.by по техническому заданию: Vite + React 19 + TypeScript, Tailwind CSS 4, shadcn/ui, Magic UI (marquee), Motion, react-router.

- Сайт: https://farik9797.github.io/20sotok/
- Локально: `npm install`, затем `npm run dev` и открыть http://localhost:5173/20sotok/
- Проверки: `npm run lint`, `npm run build`

Деплой автоматический: push в `main` → GitHub Actions → GitHub Pages.
